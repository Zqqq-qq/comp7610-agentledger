# 新前端验收与演示

后端合约不需要改动或重新部署；使用你们此前在 Sepolia 的实际地址。

1. 启动 start-frontend.ps1，使用装有 MetaMask 的 Chrome / Edge 打开 http://127.0.0.1:8090 。
2. 点击 Contracts，填入原 IdentityRegistry 和 ReputationRegistry 地址。Verify & save 应成功；如果 RPC 超时，选择 dRPC backup 重试。链上已有 Agent 应出现在列表。
3. 使用原有身份也可以演示授权；若需展示注册，连接 A，打开 Register an agent，点击 Use the local example card 或输入公开 URI。
4. 点击 Register on-chain，在钱包确认。页面应经过钱包确认、Pending、成功回执状态，并显示从 Registered 事件解析出的 Agent ID。记录交易哈希及 block。
5. 打开 Reputation，使用 A，填真实 Agent ID 和 B 的地址，签署授权；复制 JSON。保持域名 ArcAgentReputation。
6. 打开右上角钱包菜单。如果 B 在下拉列表中直接选择 B；没有则点击 Choose another account，在钱包权限界面授权 B，再选择 B。页面地址及 Active account 应是 B；授权 JSON 应保留。
7. 切换到 Submit feedback，粘贴 JSON。预览应显示 Selected wallet matches the reviewer。选择整数评分并确认交易。
8. 等待成功回执，回到列表刷新。新身份首次评价 90 分，应显示 1 review、90/100；已有身份按实际聚合计算。
9. 使用现有 Remix 实例读取 ownerOf、tokenURI、getSummary，结果应与网页一致；在 Sepolia Etherscan 核对两个交易 Success。
10. 可检查拒绝路径：A 不能给自己评价；错误网络/评分合约的授权不能提交；重复 nonce 不能再次评分；钱包取消操作后按钮可以再次使用。

验证前端不能替代钱包授权。不要为了录屏在源代码中填虚构数据或把测试输出称为实际链上成功。
